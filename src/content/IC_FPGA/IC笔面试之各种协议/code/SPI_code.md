	### 前置说明

- 指令：
	- WREN（写使能指令）：8’b0000_0110(06h)
	- BE（全擦除指令）：8’b1100_0111(C7h)
	- SE（扇区擦除指令）：8’b1101_0000(D8h)
	- PP（页写指令）：8’b0000_0010(02h)
	- READ（读指令）：8’b0000_0011(03h)
- 擦除：讲某个区域的所有存储单元设置为全1

#### Flash全擦除

以FLASH芯片W25Q16为例，其存储容量为16Mbit，阅读芯片手册得以绘制全擦除操作时序。

![完整全擦除操作时序图|700](完整全擦除操作时序图.png "完整全擦除操作时序图")

通过芯片手册的参照表可知：
- 建立时间$t_{SLCH}$：片选信号S下降沿到第一个有效数据写入时，$t_{SLCH}$必须大于等于5ns；
- 保持时间$t_{CHCH}$：最后一个有效数据写入时到片选信号上升沿时间，$t_{CHCH}$必须大于等于5ns；
- 片选信号最小延迟时间$t_{SHCL}$：片选信号自上一个上升沿始到下一个下降沿止，这之间的时间段必须大于等于100ns；
- 由芯片手册中可知：在每一次页写操作(PP)、扇区擦除(SE)、全擦除(BE)和写状态寄存器(WRSR)操作之前，都需要先进行写使能指令的写入操作，写使能指令简称为WREN，即完整擦除流程需要先写入写使能指令，再写入全擦除指令。

#### Flash扇区擦除

![完整扇区擦除操作时序图.png](完整扇区擦除操作时序图.png "完整扇区擦除操作时序图")

- 前半部分同上，后半部分先发送SE（扇区擦除指令），再发送擦除地址，该24bit地址由：扇区地址、页地址和字节地址构成。

#### Flash页写

![完整页写操作时序图](完整页写操作时序图.png "完整页写操作时序图")

- Flash芯片一页最多存储256Byte数据，这表示页写操作一次最多向Flash芯片写入256字节数据；
- 前半部分同上，后半部分先发送PP（页写指令），再发送擦除地址，该24bit地址由：扇区地址、页地址和字节地址构成，而且依次发送多个字节数据；
- 数据写入字节首地址不是该页的首地址，且后续存储空间不够这次页写的数据量，那么超出部分会以8’b0000_0000为字节首地址顺序写入本页，**覆盖**改地址之前存储的数据。

#### Flash连续写

每次进行一次页写操作，每次页写写一个字节，在页写操作完成后更新下一次页写地址，地址+1；

#### Flash读操作

![数据读操作时序图.png](数据读操作时序图.png "数据读操作时序图")

- 写入读操作指令前不需要和之前一样先写入WREN指令，且执行数据读操作过程中，片选信号拉低后和拉高前无需做规定时间等待；
- 主机写入读指令 -> 主机写入24bit地址（扇区、页、字节） -> 从机向主机发送相应地址的数据；
- 除非主机拉高片选信号，否则从机会不断按地址顺序返回数据给主机。
### 模块说明（以全擦除为例）

![全擦除模块框图](全擦除模块框图.png "全擦除模块框图")

- 输入信号：
	- 时钟信号50MHz
	- 复位信号低电平有效
	- key为按键触发信号
- 输出信号：
	- cs_n：Flash的片选信号，**低电平有效**
	- sck：Flash串行时钟
	- mosi：Flash主输出从输入信号

### 波形图

![Flash全擦除整体波形图.](../../../../public/images/posts/sv_learning_note/Flash全擦除整体波形图.png "全擦除模块框图Flash全擦除整体波形图.)

使用状态机可以方便实现SPI全擦除的整体流程：初始状态(IDLE)、写使能状态(WR_EN)、两指令间等待状态(DELAY)、全擦除状态(BE)。

- 波形说明
	- 中间信号：
		1. `cnt_sck`：由Flash芯片手册可知，Flash读操作的时钟频率sck上限为20MHz，写操作上限为50MHz，为了让主机切换读写不变更时钟，且便于分频的角度直接给系统时间进行4分频，产生12.5MHz作为sck输出时钟，`cnt_sck`作为4分频计数器；（该计数器生效条件为`((state == WR_EN) && (cnt_byte == 1'b1)) || ((state == BE) && (cnt_byte == 3'd5))`)
		2. `cnt_clk`：不管是主机写入写使能指令还是擦除指令，都要传输8bit数据，1bit为4个周期系统时钟，故需要计数32次为一个完整指令写入周期；
			- 在一次完整的时序中，需要满足建立保持时间，以及DELAY状态最短时间，因为一次完整指令写入周期为$32*20=640ns$，满足前面提到的3个时间，故考虑节省寄存器资源的角度，将这些时间统一以640ns进行考量；
		3. `state`：寄存当前状态值；
		4. `cnt_byte`：当此时处于除了IDLE外的状态，`cnt_byte`对计数器`cnt_clk`的计数周期进行计数，使用这两个计数器作为约束条件就可以实现状态机的状态跳转。
		5. `cnt_bit`：在进行指令传输时进行bit计数，计数时钟为`sck`，其他状态为0；（计数条件类似`sck`->`cnt_sck == 2'd2`）
	- 输出信号：
		- `sck`：输出给从机的时钟信号，由`cnt_sck`作为条件使能：`cnt_sck == 2'd2`时拉高，`cnt_sck == 2'd0`时拉低；
		- `cs_n`：输出给从机的片选信号；默认拉高，IDLE状态拉高 -> 按键按下时进行写指令状态，此时拉低 -> WREN跳变到状态DELAY时拉高 -> DALAY跳变到状态BE时拉低  -> BE结束跳回IDLE时拉高；
		- `mosi`：输出给从机的数据：特定状态特定`cnt_byte`值时，在`cnt_sck`低电平时赋值：`mosi <= WR_EN_INST[7 - cnt_bit];`和`mosi <= BE_INST[7 - cnt_bit];`通过减去cnt_bit从MSB到LSB赋值特定地址。
