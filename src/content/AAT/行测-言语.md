## 片段阅读

### 中心理解题（主旨概括）

解题步骤：
1. 确定题型
	- 主旨类：（提问）旨在/意在/说明...
	- 概况类：总结/归纳/概括
2. 注意
	- 选项单纯概括文段表层意思即可
	- 常见错误选项：无中生有、过度引申
3. **方法：寻找中心句**
	- 有中心句：同义替换；
	- 无中心句：全面概括；
	- 中心句的确定
		- 1、锁定关键词（三种）
			- 关键词：[[转折]]、[[因果]]、[[并列]]、[[必要]]；（出现多次关联词看最后一个）
			- 主题词：文段围绕的核心（反复出现的词[^1] ）；
			- 程度词：尤其、更、无疑；
		- 2、行文脉络（总句和分句）
4. 秒杀技巧
	- 1、重点关注首尾句——正确选项一般是与之相同、相似的表述；
	- 2、绝对化语气的选项（绝对、唯一等词）—— 一般直接排除
### 中心理解题——主题词

定义：主题词是文段围绕的核心话题。——正确选项需要包含主题词

判断方法：
1. 中心句围绕的核心话题；
2. 每句话都围绕的相同话题

【干扰选项特征】
1. 主题词缺失；
2. 主题词偷换；
3. 主题词范围扩大或缩小；
4. 主题词片面

例题段落分析1
>①通过“是”来下定义，引出话题；
>②“由于”引导原因（非重心）；
>③举例论证；
>④”通过“引导**对策**。（核心在于**对策**！）
### 中心理解题——行文脉络

理论要点：把握中心句以及分述句的特点

1. 中心句特征
	- 有重点词提示的观点——关注关联词（[[转折]]、[[因果]]、对策、代词）和程度词（关键是、根本是、更重要的是）
	- 无重点词提示的观点——排除分句（重点关注首尾句）
2. 分述句特征
	- 引入型分述
		- 背景铺垫：随着、目前、当前、近年来、在...环境下...
		- 定义引入：……是/指/被称为……
		- 对比引入：与XX相比*一样*、XX是被参照对象
	- 论述型分述——起到解释/加强观点的作用
		- 举例论证：比如、好比、有些、一些……、名人说……（<font color="red">习总说……则一定重点看</font>）
		- 数字资料：统计、数字、文献、报告、调研等
		- 正反论证（正反两方面论证）
			- 如果……+正确做法+好处   -|
			- 如果……+错误做法+危害   -| → 重点看千授引论证的前/后一句话
		- 原因解释：因为、出于、换言之、在……方面、从……角度看
	- 作用：判断中心句；排除干扰选项（快速阅读）
> **一般“总”即为中心句——对比答案，同义替换**
#### 小结
- 行文脉络（**总句**是重点）
	- 总-分
		- 提出观点 —— 论证观点
		- 提出观点 —— 解释/分析/说明
	- 分-总
		- 提出问题 —— 解决问题
		- 列举问题 —— 提出观点
		- 分析原因 —— 得出结论
	- 总-分-总
		- 提出问题 —— 分析 —— 解决问题
		- 提出观点 —— 论述 —— 重申
	- 分-总-分：背景/现状+观点/对策+举例/解释（关注两个字”**因此**“）
### 标题填入题

- 一、提问方式
	- 最适合做这段文字标题/题目的是……
- 二、理论要点
	- 1. 内容：契合中心
	- 2. 形式：生动形象
	- **【注意】** 内容+形式 >内容>形式
- 三、不同文种的解题技巧
	- 1. 新闻类：提炼**导语** -> 一般在文段开头
	- 2. 说明文：明确说明对象+概括要素
	- 3. 议论文：提炼论点或**对策**（议论文组成：论点+论据+论证）
	- 4. 其他
		- 散文类：注重作者内心的情感表达 => 正确标题一般有作者感情倾向
		- 故事类：标题拟定 => 从故事结果入手，分析原因，感悟道理（标题围绕道理拟定、突出积极向上的意义）

### 细节理解题

- 一、细节判断题
	- 1. 提问方式：下列说法正确/不正确、符合/不符合……
	- 2. 技巧：明确设问、浏览选项；
	- 3. 正确项：能从原文当中合理推出
		- 错误选项：
			- ①无中生有（主观臆断；曲解文章）；
			- ②偷换
				概念：
				- 话题转移；eg.文段讲A但是选项说B
				- 范围改变；eg.小草→植物
				数量：
				- 较多量：大部分、很多、大多数……
				- 中间量：一些、某些、某部分……
				- 较少量：少数、少部分、少量……
				逻辑：
				- 充分条件与必要条件；eg. 文段：只要……就、选项：只有……才
				- 因果关系：不符合文章意思——强加因果、因果倒置；
				时态：
				- 过去时态：已经、曾经、过去；
				- 现在：正在……，现在……
				- 将来：将要、未来、不久
				语气：
				- 确定性语气：一定、必定、肯定；
				- 不确定性语气：可能、大概、也许；
- 二、细节查找题
	- 1. 提问方式：根据上述文段
		- ……的原因/作用/目的/结果是（）
		- 这段文字没有提及的是（）
		- A与B的区别是（）
	- 2. 技巧：审设问——定位文段（看选项）
		- 原因查找题：解题—根据行文规则；eg. 原因阐述 → 得出结论 提出观点→原因解释 
		- 目的查找题：找关键词解题 eg.为了……，结果是……

## 语句表达

### 语句填空题

- 语句填空题（语句衔接题）
	- 1. 题型（提问设式）：
	- 2. 解题思路：
		- 横线处完整独立（前后句子“。”结尾）
			- 思路一致原则：
				- 横线在开头或结尾：正确项 —— 概括已有文段；
				- 横线在中间：正确项 —— 承上启下；（涉及前文和后文的关键词）
			- 话题一致原则：抓关键词
		- 横线处句子非完整独立（前/后句子“，”衔接）：可优先考虑句子内部的提示
	- 3. 快速解题技巧
		- （1）横线位置不同，句子作用不同
		- （2）**重点注意**：关联词、行文脉络、标点符号 c.g. XXX；——。
		- （3）后文为对策，则横线应填入的是问题；

### 接语选择题

- 一、题型：作者接下来最可能讲的是……
- 二、思路：通读全文（重点关注首尾句）；保持话题一致（对比择优）
- 三、技巧（只读尾句）
	- 尾句：对策+意义 —— 正常选项：针对对策展开（常见表述：这个对策的方法、路径、思路……）
	- 尾句：问题 → 正确选项：**最优**：针对问题的对策；其次：选项无对策，可选择对该问题 *产生原因* 的描述~~或其他问题~~
	- 尾句：描述的是意义 => 正确项：围绕意义展开或举例子（贴近尾句描述）
	- 尾句（分号结尾）：与前文并列 => 正确项：对前文全面概括
- 四、常见干扰（错误项）：①无中生有；②前文已经论述；③与核心问题不一致；④内容太跳跃
- 五、注意：非常规问法 —— 接下来最不可能讲的是 => 正确项选”干扰项“ ↑ （最优：②、③）
- 六、其他注意：
	- 1、找主题词
	- 2、解题：
		- 文段先提及A，而后由A*引起* B => 下文：讲B
		- 文段先提及A，而后提及B => 下文：A与B的关系

### 语句排序题

- 一、提问方式：将以上几个句子重新排序，语序正确的是……
- 二、理论要点：
	- 1. 对比选项，确定首句；
	- 2. 确定捆绑、确定顺序、确定尾句；
	- 3. 验证
- 三、确认首句
	- 1. 首句特征
		- 背景铺垫：随着、近年来、在……大背景/大环境下、长期以来；
		- 下定义：……是、被称为……、故事/新闻事件/社会现象/名人名言；
	- 2. 非首句特征
		- 指代不清的指代词：这、那、其、它、此……
		- 关联词的后半部分：但是、也、还……
		- 解释说明：具体而言、通俗的讲、假设论证……
- 四、确定捆绑
	- 1. 关联词
		- 配套关联词：只有……才……、因为……所以……
		- 单独关联词：只出现”但是“（前后两句意思相反）；”同时“（前后两句意思相同）；”然而“（前后两句一般语义相反或感情色彩相反[^2]）；
	- 2. 指代词：指代对象+指代词
- 五、确定顺序
	- 1. 时间顺序：过去 — 现在 — 未来；朝代顺序 — 唐宋元明清
	- 2. 逻辑顺序：观点+解释说明/举例/数据；提出问题+分析问题+解决问题；A和B+先A后B；认知逻辑 — 由表及里、是什么/为什么/怎么办
	- 3. 其他顺序：大概念 -> 小概念；宏观 -> 微观；抽象 -> 具体
	> 注：不要自己排序：浪费时间
- 六、确定尾句
	- 1. 结论句：因此、所以、于是……
	- 2. 对策句：应该……、需要……、采取……

## 逻辑填空

- 一、词的辨析
	- （一）词义侧重（看选项词语本身）
		- 拆字组词：用不一样的字单独组词；eg. 鉴别 vs 鉴赏：别 — 区别；赏 — 欣赏
		- 整词搭配：用整个词进行组词搭配；eg. 方寸 vs 寸步：方寸 — 面积地方；寸步 — 侧重极短距离
	- （二）搭配对象
		- 重视[[行测词语积累]]；e.g.《求是网》、《人民网》、《学习强国》、《环球网》
		- 常用词搭配；eg. 敬畏自然、探讨问题、承载梦想……
		- 热点搭配；eg. 政治互信、经济互融、人文互通……
	- （三）程度轻重 — 从词语、语义方面分析：与文段保持一致
		- eg.（1）领导很生气，（ 后果）严重  A.后果     B. 结果
			（2）任意（中性） vs 肆意（贬义）
	- （四）感情色彩（中、褒、贬）
	- （五）三字词语（事业单位A类必考）
		- 详见[行测词语积累](行测词语积累.md)
- 二、语境分析
	- （一）关联关系
		- 转折关系
			- 标志词：eg. 但是……
			- 正确答案：一定是转折前后语义相反，或者感情色彩相反；
		- 递进关系
			- 标志词：e.g. 而且……
			- 正确答案：所填词语，前后语义相关，程度一般“前轻后重”；
		- 因果关系
			- 标志词：原因词：因为、由于；结果词：因此、所以、导致；
			- 正确答案：所填词语保持前后因果一致；
		- 并列关系
			- 近义并列：标志符号为“、”或”，“；正确答案前后语义相近；
			- 反义并列：标志词：不是……而是……、反之……；正确答案选择语义相反；
			- 句式相同/相近：结合前后语境分析所填词语与已知词语近义还是反义；
	- （二）对应关系
		- 解释类对应
			- 类型一 · 有标志：
				- 标志词：即、可谓、 比如、相当于、换言之；
				- 标志符号：”：“、”——“
			- 类型二 · 无标志：前后分句会进行解释、完整句提示（句式：<ins> 　　</ins>，分句；分句，<ins> 　　</ins>）
		- 重点词对应
			- 指代词：总结前文；（e.g. 这、此）
			- 主题词：所填词语需要呼应主题词
			- 形象表达：拟人、比喻等 —— 优先选择与形象表达的内容契合的词
