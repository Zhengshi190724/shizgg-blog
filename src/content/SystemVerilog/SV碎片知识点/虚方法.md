### 虚方法的一些要点

1. 类中的方法在定义的时候通过添加`virtual`关键字来声明一个虚方法，虚方法是一个基本的多态性结构.
2.  虚方法为具体的实现提供一个原型,也就是在派生类中,重写该方法的时候必须采用一致的参数和返回值.
3. 虚方法可以重写其所有基类中的方法,然而普通的方法被重写后只能在本身及其派生类中有效。
4. 每个类的继承关系只有一个虚方法的实现,而且是在最后一个派生类中。

### 虚方法的例子1

#### 定义两个类

- 父类：
	- 定义变量a、b并赋值；
	- function1显示a的值；
	- function2用virtual定义，显示b的值。
- 子类：
	- 继承父类变量a、b并赋其他值；
	- function1显示a的值；
	- function2用virtual定义，显示b的值。

``` systemverilog
class packet;
	int a =1;
	int b =2;
	function void display_a;
		$display("packet::a is %d",a);
	endfunction
	
	virtual function void display_b;
		$display("packet::b is %d",b);
	endfunction
endclass

class my_packet extends packet;
	int a =3;
	int b =4;
	function void display_a;
		$display("my_packet::a is %d",a);
	endfunction
	
	virtual function void display_b;
		$display("my_packet::b is %d",b);
	endfunction
endclass
```

#### 调用类

``` systemverilog
module top;
	packet p1;
	my_packet p2;
	
	initial begin
		p1=new();
		p2=new();
		p1 = p2;
		
		p1.display_a;
		p1.display_b;
	end
endmodule
```

- 子类父类声明句柄，在`initial`模块中创建对象，将父类句柄指向子类对象，输出类中两个function：
	- 第一个调用`p1.display_a;`将输出`packet::a is 1`，因为程序会调用访问内存中**类对象p2中p1的部分**，而此时发现display_a是一个普通方法，此时直接调用并结束访问。
	- 第二个调用`p1.display_b;`将输出`packet::b is 4`，程序同样找到类对象p2中p1的部分,此时发现display_b是个虚方法，这时其会咨询系统，查看整个p2在定义的时候是否重写了该方法.系统发现在p2中(除了p1外)确实重写了该方法，为此，程序会**直接调用p2重写的实现**。

### 虚方法的例子2

#### 不使用虚方法

``` systemverilog
module po;
	class Packet;
		int crc;
		extern function int compute_crc();
	endclass

	function int Packet::compute crc();
		return 1;
	endfunction

	class MyPacket extends Packet;
		extern function int compute_crc();
	endclass
	
	function int MyPacket::compute_crc();
		return 0;
	endfunction

	function int crc(Packet pkt);
		crc = pkt.compute_crc();
	endfunction
	s
	initial begin
		Packet p1 = new();
		MyPacket p2 = new();
		p1.crc = p1.compute_crc();
		$display("p1.crc = %0d", p1.crc);
		p2.crc = p2.compute crc();
		$display("p2.crc = %0d", p2.crc);
		p1.crc = crc(p1);
		$display("p1.crc = %0d", p1.crc);
		p2.crc = crc(p2);
		$display("p2.crc = %0d", p2.crc);
	end
endmodule
//<https://blog.csdn.net/llxxyy507>
```

- 定义：
	- 定义父类和基类时使用`extern`定义`function`，在`class`外部详细给出`function`具体实现形式。
	- 父类和子类都定义了一个`function`，功能分别是返回值1和值0；另外，第三个`function` `crc`，参数列表为父类句柄，功能依然是返回函数`compute_crc`的`crc`的值。
- 结果：
	- 前一组`p1.crc`和`p2.crc`，赋值的是各自自身的函数返回值，故`p1.crc = 1`而`p2.crc = 0`，第二组`p1.crc`和`p2.crc`，赋值的是父类句柄的函数返回值，虽然p1指向子类对象，由于`function`没有用虚方法，故`p1.crc`和`p2.crc` 的值都为1。

#### 使用虚方法

``` systemverilog
module po;
	class Packet;
		int crc;
		extern virtual function int compute_crc();
	endclass

	function int Packet::compute crc();
		return 1;
	endfunction

	class MyPacket extends Packet;
		extern virtual function int compute_crc();
	endclass
	
	function int MyPacket::compute_crc();
		return 0;
	endfunction

	function int crc(Packet pkt);
		crc = pkt.compute_crc();
	endfunction
	s
	initial begin
		Packet p1 = new();
		MyPacket p2 = new();
		p1.crc = p1.compute_crc();
		$display("p1.crc = %0d", p1.crc);
		p2.crc = p2.compute crc();
		$display("p2.crc = %0d", p2.crc);
		p1.crc = crc(p1);
		$display("p1.crc = %0d", p1.crc);
		p2.crc = crc(p2);
		$display("p2.crc = %0d", p2.crc);
	end
endmodule
//<https://blog.csdn.net/llxxyy507>
```

- 定义：
	- 定义父类和基类时使用`extern`定义`function`，且父类的方法定义为`virtual`（子类是否定义`virtual`都可），在`class`外部详细给出`function`具体实现形式。
	- 父类和子类都定义了一个`function`，功能分别是返回值1和值0；另外，第三个`function` `crc`，参数列表为父类句柄，功能依然是返回函数`compute_crc`的`crc`的值。
- 结果：
	- 前一组`p1.crc`和`p2.crc`，赋值的是各自自身的函数返回值，故`p1.crc = 1`而`p2.crc = 0`，第二组`p1.crc`和`p2.crc`，赋值的是父类句柄的函数返回值，p1指向子类对象，由于`function`用了虚方法，故`p1.crc`和`p2.crc` 的值都为分别为1和0。
