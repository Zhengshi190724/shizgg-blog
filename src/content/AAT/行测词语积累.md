### 二字词语

1. 割裂、模糊、混淆、杂糅区别：
	- 割裂：把统一的事物分裂开；
	- 模糊：不清楚、不分明；
	- 混淆：使界限不分明；
	- 杂糅：把不同事物混杂在一起。
2. 樊篱：本义指竹木构筑的篱笆类围栏。作为比喻用法时，该词多用于描述思想观念、技术范式或制度架构等抽象事物形成的限制性框架。
3. 迎合、暗合的区别：
	- 迎合：指故意使自己的言语或举动适合别人的心意；
	- 暗合：指没有经过商讨而意思恰巧相合。

### 三字词语

1. 定盘星：比喻起重要作用的骨干力量；
2. 领头羊：带领大家/行业前进的领头羊/领袖；
3. 主旋律：精神基调：
4. 两面光：比喻两方面都不得罪人；
5. 放大镜：比喻对事物详细审查；
6. 金钥匙：比喻有效的方法、窍门；

### 四字词语

1. 波诡云谲：形容事物变换莫测（多用于历史、国际局势、官场、金融市场）；
2. 筚路蓝缕：形容创业艰难；
3. 鬼斧神工：搭配大自然、建筑、雕塑；
4. 事物发展不同阶段
	1. 发展初期：初露峥嵘、悄然升起、崭露头角；
	2. 上升阶段：日新月异、欣欣向荣、如火如荼、方兴未艾，势如破竹；
	3. 鼎盛时期：如日中天、登峰造极、繁荣昌盛；
	4. 衰落时期：江河日下、日薄西山、盛极而衰；
	5. 消亡时期：日暮穷途、穷途末路；
5. 遴选：意为慎重选拔或挑选，该词既可指人才选拔行为，也可泛指各类优选过程；
6. ‌“**批露**”其实是“**披露**”的常见错别字；
7. 惴惴不安、不寒而栗、望而生畏、胆战心惊：
	- 惴惴不安：心里发愁，担心出事（焦虑）
	- 不寒而栗：想起/看见恐怖阴暗的事，后背发凉（极致惊悚）；看到残酷毁灭性的悲惨事实
	- 望而生畏：看着就不敢靠近（怕气场威严）
	- 胆战心惊：当场撞见危险，吓得发抖（直面险境）
8. 讳莫如深：形容隐瞒得很深，惟恐他人知道。
9. 休戚相关：指彼此之间的祸福互相关联。
10. 薪火相传和彪炳千古：
	- 薪火相传：一代一代的传下去，通常指技艺或传承；
	- 彪炳千古：形容伟大的业绩流传千秋万代。
11. 弹冠相庆、低头折节、额手称庆、击节赞叹：
	- 弹冠相庆：指官场中一人当了官或者升了官。同伙就互相庆贺有官可做；
	- 低头折节：指丧失气节、屈服于他人；
	- 额手称庆：指两手在胸前相握，举到额头，表示庆幸、庆贺；
	- 击节赞叹：形容对别人的诗文或艺术等的赞赏。
12. 洋洋洒洒、纷纷扬扬：
	- 洋洋洒洒：一般指写文章很快；
	- 纷纷扬扬：形容雪、花等多而杂乱地在空中飘舞；
13. 微言大义：指的是用精微简练的语言蕴含深刻的道理或大义，常用来形容文章或话语言简意赅却内涵丰富。
14. 石破天惊、惊天动地：
	- 石破天惊：本意形容箜篌的声音，忽而高亢，忽而低沉，能够形容台风暴雨的声音。
	- 惊天动地：形容某个事件的声势或意义极大。
15. 不一而足：指同类事物不止一种，而是很多，无法列举齐全。
16. 一文不名：意为身上没有一文钱，形容极度贫困。
17. 量入而出：指根据收入情况确定支出额度，强调收支平衡的原则。
18. 重典治乱、猛药去疴、刮骨疗毒、惩前毖后、手到病除
	- 重典治乱：面对秩序混乱的状况，使用严厉的法令进行强力整治，依靠刚性约束恢复秩序；*侧重外部强力整治，重拳整治顽疾乱象*；
	- 猛药去疴：针对长年积累的严重弊病，采取力度强、效果猛烈的整治措施，彻底根除顽疾。*侧重外部强力整治，重拳整治顽疾乱象*；
	- 刮骨疗毒：侧重**自我整治、刀刃向内**，多用于自我革新、肃清内部深层腐败与作风问题。
	- 惩前毖后：侧重处置目的，重在警示教育，防范再犯；
	- 手到病除：侧重解决问题效率高、手段精准，见效迅速。
19. 未雨绸缪、防患未然：
	- 未雨绸缪：没事先做好各种准备；（适用场景更广：财务规划、人才储备、项目预案、生活规划等无危险的筹备都能用。）
	- 防患未然：危险没来，提前消除隐患避免出事。（适用于安全生产、治安、灾害、腐败风险、消防等存在危害性的场景。）
20. 瞻前顾后：褒义：做事前考虑周全、审慎负责；贬义：顾虑太多、犹豫不决、缺乏果断；
21. 望其项背、望尘莫及、鞭长莫及、不可企及、等量齐观、同日而语、相提并论、望洋兴叹
	- 望其项背：能看见别人的颈项和后背，指**赶得上、比得上**。只能用于否定句，难以/不能...
	- 望尘莫及：望见前面人马扬起的尘土却追赶不上，**远远比不上、赶不上**；
	- 鞭长莫及：鞭子虽长，也打不到马肚子；比喻**距离太远、力量达不到，客观上无力顾及**；
	- 不可企及：企：踮脚。踮起脚也够不着，形容差距极大，**完全比不上**；
	- 等量齐观：把不同事物同等看待，侧重两者水平相当、可比；
	- 同日而语：把同一事物放在不同**时间**比较，多用于**否定**，表差距大，不能放在一起比较；
	- 相提并论：把有差距的人 / 事物放在一起谈论，多否定句，表二者差距大，**不能对比**；
	- 望洋兴叹：看见大海感叹自己渺小，指**因能力不足、条件不够而无可奈何**。
22. 金科玉津：比喻必须遵守、不能变更的信条；
23. 明察秋毫、洞若观火、了如指掌：
	- 明察秋毫：观察细致，发现细微之处；看细节、查漏洞；搭配审查、办案、辨别细节；
	- 洞若观火：洞察透彻，看透本质根源；看本质、看大局；分析局势、剖析问题、看透人心；
	- 了如指掌：全面熟知，全部信息熟记；记信息、知全貌；掌握资料、熟悉地域/人员/流程。

### 词语褒贬性：

#### 贬义词
1. 粉墨登场：原指演员化妆上台演戏，现比喻坏人乔装打扮，登上政治舞台；
2. 好为人师：指不谦虚，喜欢以教育者自居；
3. 亦步亦趋：指的是自己没有主张，或者为讨好别人，事事模仿、讨好或依从别人；
4. 弹冠相庆：指官场中一人当了官或者升了官。同伙就互相庆贺有官可做，可形容坏人得意；
5. 高谈阔论：多为贬义，指的是大发议论或者漫无边际的议论；
	- 特殊情况下：也可指志趣高雅、见地高超；

#### 褒义词：
1. 不刊之论：多形容言论确当、无懈可击；
2. 危言危行：说正值的话，做正直的事；
