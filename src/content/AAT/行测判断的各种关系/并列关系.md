- 一、常见的并列关系词语
	- （一）矛盾关系 —— 非A即B
		- 1. 有 : 无（有罪 : 无罪//有关 : 无关//有限 : 无限）
		- 2. 虚 : 实（虚词 : 实词//实体法 : 程序法）
		- 3. 是 : 非（科学 : 非科学//处方药 : 非处方药）
		- 4. 天 : 人（自然灾害 : 人为灾害//自然景观 : 人为景观）
		- 5. 开 : 关（开灯 : 关灯//睁眼 : 闭眼）
		- 6. 其他：
			- （1）宝石行业 —— 分红和蓝宝石两种
			- （2）有色金属 : 黑色金属
	- （二）反对关系
		- 1. 寒性食物 : 热性食物（食物有寒、凉、温、热四性）
		- 2. 食草动物 : 食肉动物（其他：杂食性动物）
- 二、常见全同关系
	- 芝麻：脂麻、油麻；
