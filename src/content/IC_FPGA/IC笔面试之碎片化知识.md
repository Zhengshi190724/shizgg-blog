1. Moore和Mealy状态机：
	- Moore型状态机：最后的输出只和当前状态有关而与输入无关则称为；
	- Mealy型状态机：最后的输出不仅和当前状态有关还和输入**有关**；
	- Mealy型一般比Moore型少一个状态，mealy型的第三段条件更多；
		- moore型：`else if (current_state == S4) data_out <= 1'b1;`
		- mealy型：`else if (current_state == S3 && data_in == 1'b1) data_out <= 1'b1;`。
	- 输入有关mealy型。
2. SRAM和DRAM：
	- 组成：SRAM为6个晶体管；DRAM是1个晶体管和1个电容；
	- 区别：SRAM 速度更快但成本高，主要用于 CPU 缓存；DRAM 容量大成本低，主要用作电脑主内存。
3. 至少要几个2选1选择器能够构成一个异或门？
	- 答：2个；第1个MUX：选择端接A，输入端接B_N和B，第二个MUX做成一个非门用来生成B_N；
4. 数字芯片FLOW：**规R功逻D形，布电标时布；寄静功物E签，G流**。
	- **规格与架构设计**：制定SPEC，包含芯片功能、性能、功耗、面积、接口、时钟、电源等；
	- **RTL设计**；
	- **功能**验证：仿真、UVM、断言、覆盖率、形式验证等；
	- **逻辑综合**：加上时序约束SDC、标准单元库，综合成**门级网表**；
	- **DFT插入**：可测试性设计，插入扫描链、JTAG、MBIST、边界扫描等；
	- **形式验证/等价性检查**：检查RTL与综合后网表、DFT后网表是否功能一致，常用LEC；
	- **布局规划** Floor plan：确定芯片die/core面积、IO 位置、宏单元位置、模块划分等；
	- **电源规划** Power plan：设计电源网格、地网格、电源域、IR drop 裕量，保证供电可靠；
	- **标准单元布局** Placement：把标准单元摆放到芯片版图中，优化时序、功耗和面积；
	- **时钟树综合** CTS：构建时钟网络，控制时钟偏差 skew、延迟 latency、功耗和时序；
	- **布线** Routing：连接所有单元和宏单元，满足 DRC、时序和信号完整性要求；
	- **寄生参数提取**：提取电阻电容寄生参数，生成SPEF文件；
	- **静态时序分析** STA：检查建立时间、保持时间、串扰、OCV 等，覆盖不同工艺角 PVT；
	- **功耗、IR drop、EM分析**：分析动态/静态功耗、电压降，确保电源网络和可靠性达标；
	- **物理验证**： DRC 设计规则检查、LVS 版图与原理图一致性检查、ERC 电气规则检查；
	- **ECO**：对时序、功耗、DRC、LVS、IR drop等问题做工程变更，反复迭代直到收敛；
	- **签核 Signoff**：时序、功耗、物理、可靠性、DFM 等所有检查通过，达到流片标准；
	- **GDSII/OASIS 输出**： 生成最终版图数据，交给晶圆厂制作掩模；
	- **Tapeout流片**：掩模制造、晶圆生产、封装、测试、硅后验证。
5. 三种冒险原因与解决：
	- 数据冒险：
		- 原因：指令间存在数据依赖，后面指令需要前面指令的结果，但结果尚未写回寄存器，典型 —— 写后读；
		- 解决：数据前递（Forward）、流水线阻塞（stall）、编译器调度；
	- 结构冒险：
		- 原因：硬件资源不足，多条指令在同一时钟周期竞争同一资源；
		- 解决：**硬件资源分离**（哈佛结构）、流水线阻塞（stall）；
	- 控制冒险：
		- 原因：分支或跳转指令会改变PC值，而跳转条件是否成立、目标地址在哪，要到EX阶段（甚至更晚）才能确定；
		- 解决：分支预测（Branch Prediction）、延迟槽、流水线冲刷（Flush）；
6. 查找表（Look-Up-Table)简称为LUT，LUT本质上就是一个**RAM**。 目前FPGA中多使用**4输入**的LUT，所以每一个LUT可以看成一个有**4位地址线**的16x1的RAM。 当用户通过**原理图或HDL语言描述**了一个逻辑电路以后，**PLD/FPGA开发软件**会自动计算逻辑电路的所有可能的结果，并把结果事先写入RAM,这样，每输入一个信号进行逻辑运算就等于输入一个地址进行查表，找出地址对应的内容，然后输出即可。
