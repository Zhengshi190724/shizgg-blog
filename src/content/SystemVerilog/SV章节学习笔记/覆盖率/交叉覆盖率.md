### 概述

- 记录某一时刻多个变量之间值得组合情况，使用`cross`—— 交叉覆盖率。
- cross语句只允许带coverpoint或者简单的变量名。
简单代码片段示例：
``` systemverilog
class Transaction;
	rand bit [3:0] kind;
	rand bit [2:0] port;
endclass
Transaction tr;
covergroup CovPort;
	kind: coverpoint tr.kind;
	port: coverpoint tr.port;
	cross kind, port;
endgroup
```

### 排除部分cross bin

``` systemverilog
covergroup Covport;
	port: coverpoint tr.port
		{bins port[] = {[0:$]};
	}
	kind: coverpoint tr.kind {
		bins zero = {0};
		bins lo = {[1:3]};
		bins hi[] = {[8:$]};
		bins misc = default;
	}
	cross kind, port {
		ignore_bins hi = binsof(port) intersect {7};
		ignore_bins md = binsof(port) intersect {0}&&binsof(kind) intersect {[9:11]};
		ignore_bins lo = binsof(kind.lo);
	}
endgroup
```

- 通过使用`ignore_bins`、`binsof`和`intersect`分别指定coverpoint和值域，清除不关心的cross bin。
- 上述代码，后续通过ignore_bins忽略了port = 7的情况，忽略了port = 0且kind = 9~11的情况，且忽略了kind = 1~3的情况/

也可以通过binsof指定某些感兴趣的cross bin。

``` systemverilog
// 写法一：
class Transaction;
	rand bit a, b;
endclass
covergroup CrossBinNames;
	a: coverpoint tr.a
	{ bins a0 = {0};
		bins a1 = {1};
		type_option.weight=0;} // 不计算覆盖率
	b: coverpoint tr.b
	{ bins b0 = {0};
		bins b1 = {1};
		type_option.weight=0;} // 不计算覆盖率
	ab: cross a, b
	{ bins a0b0 = binsof(a.a0) && binsof(b.b0);
		bins a1b0 = binsof(a.a1) && binsof(b.b0);
		bins b1 = binsof(b.b1); }
endgroup
// 写法二：
class Transaction;
	rand bit a, b;
endclass
covergroup CrossBinsofIntersect;
	a: coverpoint tr.a
		{ type_option.weight=0; } // Don’t count this coverpoint
	b: coverpoint tr.b
		{ type_option.weight=0; } // Don’t count this coverpoint
	ab: cross a,b
		{ bins a0b0 = binsof(a) intersect {0} && binsof(b) intersect {0};
		bins a1b0 = binsof(a) intersect {1} && binsof(b) intersect {0};
		bins b1 = binsof(b) intersect {1}; }
endgroup

```
