- **大端模式（Big-Endian）**:
	- **高位字节**存储在**低地址**，**低位字节**存储在**高地址**。
	-  例如：`int value=0x12345678`在内存中的存储方式：
		`地址:0x1000 -> 0x12(高位字节)`
		`地址:0x1001 -> 0X34`
		`地址:0x1002 -> 0x56`
		`地址:0x1003 -> 0x78(低位字节)`
	- 定义赋值时，左边高位右边地位；而常见调试器看内存地址时，从左到右是从低位到高位；
	- 典型应用：网络协议、PowerPC架构、Unix服务器等
	- 影响：跨平台数据交换需字节序转换
- **小端模式（Little-Endian）**:
	- **低位字节**存储在**低地址**，**高位字节**存储在**高地址**。
	-  例如：`int value=0x12345678`在内存中的存储方式：
		`地址:0x1000 -> 0x78(低位字节)`
		`地址:0x1001 -> 0X56`
		`地址:0x1002 -> 0x34`
		`地址:0x1003 -> 0x12(低位字节)`
	- 一个字节一个字节的存放，存放顺序也是从地位到高位存放，数据地位存低位地址，数据高位存高位地址；若是赋值`int a = 0x1234567`
		`地址:0x1000 -> 0x67(低位字节)`
		`地址:0x1001 -> 0X45`
		`地址:0x1002 -> 0x23`
		`地址:0x1003 -> 0x01(低位字节)`
	- 典型应用：X86，ARM等
	- 影响：需注意二进制数据的兼容性
